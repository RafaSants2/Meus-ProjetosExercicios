</h1>: Essa tag serve para títulos, tendo uma hierarquia do maior até o menor (H1, H2, H3, H4...)

</p>: Essa tag é um parágrafo.

<hr>: Cria uma linha horizontal.

<br>: Se for necessário, use-o para quebrar um texto em algum lugar específico.

Símbolos: &reg; (®), &copy; (©), &half; (½)...

</img>: Tag que permite adicionar imagens de forma interna (tendo a imagem salva) e externa (de um site ou do Google, copiando o endereço de imagem). Alguns sites que não possuem direitos autorais: unsplash.com, Pexels.com

Favicon: Ícone representante de um site.
Estrutura: <link rel="shortcut icon" href="favicon.ico" type="image/x-icon">

Tipos de Textos:

  • </b> (SEM semântica) / </strong> (COM semântica): Texto Negrito - se usam para por algo em NEGRITO.

  • </i> (SEM semântica) / </em> (COM semântica): Texto Itálico - se usam para por algo em ITÁLICO.

  • </u> (SEM semântica) / </ins> (COM semântica): Texto Inserido - se usam para dar ênfase.

  • </MARK> (COM semântica): Texto Marcado - se usa para MARCAR algo.

  • </del> (COM semântica): Texto Deletado - se usa para indicar que ele deve ser lido, mas NÃO considerado..

  • </sup> (COM semântica): Texto Sobrescrito - Deixa coisas sobrescritas. EX.: x20+3

  • </sub> (COM semântica): Texto Subscrito - Deixa coisas subscritas. EX.: H2O

  • </pre>: Com a ajuda do </pre>, podemos usá-la junto com o </code> para que no site a indentação seja a mesma ao que é feito dentro dessa tag. Exemplo (como referência o Phyton):

  • </q>: serve para criar uma frase entre aspas.

CITAÇÕES COMPLETAS: Citações maiores, tendo uma quebra de linha e deslocamento horizontal para a lateral direita.

Listas:

Lista ordenada:

  1. </ol>: Aquelas que a ordem faz diferença. (OBS: posso atribui-lá usando o "type" e/ou "start", que mostra de qual numeração começará a contagem)
  2. Itens de lista (</li>): Itens que ficarão dentro da lista (</ol ou </ul) criada anteriormente.

Lista NÃO ordenada:

  • </ul>: Nessa, não faz sentido haver uma sequência, e também se usa dentro dela o </li>, ademais, é possivel usar o "type" também, colocando essa lista não ordenada com o tipo: "disc", "circle" e "square"

Links Internos e Externos:

Link Externo:

Link que aponta para outro site (que não é nosso). Usa-se a tag </a>. EXEMPLO: Esse site não é meu

</a>: essa tag é chamada de "âncora", e é com ela que podemos criar um link, se usa esse href dentro da tag para mostrar o local onde meu site vai. O target="_blank" faz com que o link aberto nos leve a outra página/aba. OBS: lembre-se que o "target" é usado apenas para sites que você quer abrir e que não são seus.

Link Interno:

Fará ligação com outra página que está dentro do nosso servidor que diz respeito com a nossa página. EXEMPLO: Meu site

Links para donwload em PDF e compactado em ZIP:

  • PDF: Para fazer um link para donwload em pdf, se usa a estrutura "donwload" (colocando o nome do arquivo que deseja ser instalado) e "type" sendo "application/pdf".

  • ZIP: Mesma coisa, a diferença é que no "type" você colocará "application/zip"

Vídeo:

</video>: tag que mostra vídeos. Se você quiser, dentro da tag "video" você pode colocar "poster", que serve para colocar uma imagem de thumb para seu vídeo. além disso, pode-se colocar o atributo "autoplay" (para reproduzir o vídeo automáticamente) e "controls", que serve para fazer o controle de áudio aparecer.

<source>:Se você quer que seja melhor de usar a tag "video", crie essa tag e, dentro dela, a tag "source", e dentro da tag "source", use "src", que vai ser usado para colocar o vídeo, além disso, coloque na tag source o atributo "type:video/mp4" caso o seu vídeo seja no formato mp4, claro.

Áudio:

</audio>: essa tag que se usa para colocar áudios, nesse caso, o áudio é posto dentro do "src" que se encontra na tag "audio", ademais, coloque "autoplay" caso queira que comece automáticamente, e "controls" para que haja o controle de áudio.
